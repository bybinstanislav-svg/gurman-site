# Как запустить сервер заказов на Яндекс Клауд (простая инструкция)

> **Вариант «на рабочем ПК в магазине»** — см. раздел в конце этого файла.

## Зачем это нужно

Сейчас сайт (гурман-супермаркет.рф) лежит в Яндекс Object Storage — это просто «файловое хранилище»: оно умеет показывать страницы, но не умеет принимать заказы. Поэтому сервер заказов (`server/server.js`) пока работает только на вашем компьютере.

Заказам нужен «компьютер», который работает 24/7 и доступен из интернета. Это **не ваш домашний компьютер**, а маленькая **виртуальная машина (ВМ) в Яндекс Клауд** — у вас уже есть туда доступ. Стоит порядка 600–800 ₽/мес.

Сайт остаётся где лежит (ничего не меняется), ВМ нужна только для заказов.

## Шаг 1. Создать виртуальную машину

1. Зайдите на [console.yandex.cloud](https://console.yandex.cloud)
2. **Compute Cloud → Создать ВМ**
3. Настройки:
   - Имя: `gurman-server`
   - ОС: **Ubuntu 24.04** (без docker-образа, обычная)
   - Диски: 10 ГБ
   - Вычислительные ресурсы: **2 vCPU (прерываемая НЕ нужна), 2 ГБ RAM** — самый дешёвый вариант
   - В разделе «Сеть»: поставьте галочки **«Разрешить доступ к серийной консоли» не нужно**, а вот **публичный IP** — «Автоматически»
   - Логин и пароль (или SSH-ключ) — запишите их
4. Нажмите «Создать». Через минуту ВМ запустится и получит адрес вида `158.160.12.34` — **запишите его, это адрес вашего сервера**

## Шаг 2. Открыть порт 3000

В Яндекс Клауд по умолчанию входящие соединения закрыты:

1. **VPC → Сеть → группы безопасности** (или «Security groups»)
2. Создайте группу `gurman` (или откройте созданную автоматически для ВМ) → **Добавить правило**:
   - Диапазон портов: `3000`
   - Протокол: TCP
   - Источник: 0.0.0.0/0
3. Привяжите эту группу к ВМ (Compute Cloud → ваша ВМ → изменить → сетевые настройки).

## Шаг 3. Установить сервер на ВМ (самый простой путь)

С вашего компьютера (PowerShell, из папки проекта — где `start-server.bat`):

```powershell
# 1. Упаковать проект (без тяжёлых лишних папок)
tar -a -c -f gurman.zip --exclude node_modules --exclude .git --exclude android --exclude .tmp-price.png .

# 2. Загрузить на ВМ и подключиться (замените логин и адрес на свои)
scp gurman.zip логин@адрес-ВМ:
ssh логин@адрес-ВМ
```

На ВМ (команды уже в SSH-окне):

```bash
# 3. Распаковать и запустить установщик — он сделает всё сам
sudo apt update && sudo apt install -y unzip
unzip gurman.zip -d gurman && cd gurman
bash setup-vm.sh
```

Установщик сам поставит Node.js, зависимости, запустит сервер и включит автоперезапуск. В конце покажет адреса сайта и кухни.

**Альтернатива через GitHub** (если репозиторий публичный):

```bash
sudo apt update && sudo apt install -y nodejs npm git
git clone https://github.com/ВАШ_ЛОГИН/gurman-site.git gurman
cd gurman && npm install && npm run build
sudo npm install -g pm2
pm2 start server/server.js --name gurman && pm2 save && pm2 startup
```

## Шаг 4. Проверить

- Откройте в браузере `http://АДРЕС-ВМ:3000` — должен открыться сайт
- Откройте `http://АДРЕС-ВМ:3000/kitchen` — экран кухни. Откройте его на планшете на кухне и держите включённым

## Шаг 5. Подключить сайт и приложение (одна строка!)

Осталось вписать адрес ВМ в начало файла `src/api.js`:

```js
const APP_SERVER_URL = 'http://158.160.12.34:3000'; // ваш адрес ВМ
```

После этого:
- **Сайт** — закоммитьте изменение и запушьте в GitHub: GitHub Actions сам пересоберёт и выложит сайт, заказы с сайта пойдут на ВМ
- **Приложение** — `npm run build` → `npx cap sync android` → Run в Android Studio
- **Кухня** — планшет открывает `http://адрес-ВМ:3000/kitchen`

## Обновление меню на сервере

После изменений (например, новые цены) на ВМ достаточно:

```bash
cd gurman
git pull
npm run build
pm2 restart gurman
```

# Вариант Б: сервер на рабочем ПК в магазине (без облака)

Подходит для старта: ноль рублей в месяц, всё работает, пока ПК включён.

## Что нужно на рабочем ПК (один раз)

1. Установить [Node.js LTS](https://nodejs.org) (при установке всё «Далее»)
2. Скопировать папку проекта на ПК (или `git clone`)
3. Запустить **`start-server.bat`** (двойной клик) — он сам установит зависимости, соберёт сайт, запустит сервер и откроет экран кухни. Первые запуск — пару минут, дальше — мгновенно

## Чтобы ПК не «засыпал» и сервер запускался сам

1. Пуск → «Электропитание» → «Настройка схемы» → **Сон: Никогда** (и экран как хотите)
2. Автозапуск: `Win+R` → введите `shell:startup` → Enter → положите туда **ярлык** `start-server.bat`

## Кто сможет заказывать

- **Внутри магазина (Wi-Fi):** сразу всё работает. Узнайте адрес ПК (`ipconfig` → IPv4, например `192.168.1.128`):
  - кухня на планшете: `http://адрес-ПК:3000/kitchen`
  - заказ с любого телефона: `http://адрес-ПК:3000`
- **Через интернет:** нужно, чтобы вас было «видно» из интернета:
  1. Позвонить провайдеру интернета и подключить **статический (белый) IP** (обычно 0–100 ₽/мес)
  2. В настройках роутера сделать **проброс порта**: внешний порт 3000 → IP рабочего ПК, порт 3000
  3. Windows брандмауэр: разрешить Node.js (галочки «Частная» и «Публичная» сети)
  4. Заказы с сайта пойдут на `http://ваш-белый-IP:3000` — впишите его в `src/api.js` (`APP_SERVER_URL`)

## Честные ограничения этого варианта

- ПК должен быть включён всегда, пока принимаются заказы (выключили ПК / Windows обновился и перезагрузился — сервер недоступен)
- Интернет в магазине станет «узким местом»: пропал интернет — пропали заказы
- При смене компа/роутера адрес поменяется — придётся обновить адрес в сайте/приложении

Когда заказов станет много — переезжайте на ВМ по инструкции выше: файл заказов `server/orders.json` просто копируется, ничего не потеряется.
