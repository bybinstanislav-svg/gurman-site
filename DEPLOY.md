# Как запустить сервер заказов на Яндекс Клауд (простая инструкция)

## Зачем это нужно

Сейчас сайт (гурман-супермаркет.рф) лежит в Яндекс Object Storage — это просто «файловое хранилище»: оно умеет показывать страницы, но не умеет принимать заказы. Поэтому сервер заказов (`server/server.js`) пока работает только на вашем компьютере.

Заказам нужен «компьютер», который работает 24/7 и доступен из интернета. Это **не ваш домашний компьютер**, а маленькая **виртуальная машина (ВМ) в Яндекс Клауд** — у вас уже есть туда доступ. Стоит порядка 600–800 ₽/мес.

Сайт остаётся где лежит (ничего не меняется), ВМ нужна только для заказов.

## Шаг 1. Создать виртуальную машину

1. Зайдите на [console.yandex.cloud](https://console.yandex.cloud)
2. **Compute Cloud → Создать ВМ**
3. Настройки:
   - Имя: `gurman-server`
   - ОС: **Ubuntu 24.04** (без docker-образа, обычная)
   - Диски: 10 ГБ
   - Вычислительные ресурсы: **2 vCPU (прерываемая НЕ нужна), 2 ГБ RAM** — самый дешёвый вариант
   - В разделе «Сеть»: поставьте галочки **«Разрешить доступ к серийной консоли» не нужно**, а вот **публичный IP** — «Автоматически»
   - Логин и пароль (или SSH-ключ) — запишите их
4. Нажмите «Создать». Через минуту ВМ запустится и получит адрес вида `158.160.12.34` — **запишите его, это адрес вашего сервера**

## Шаг 2. Открыть порт 3000

В Яндекс Клауд по умолчанию входящие соединения закрыты:

1. **VPC → Сеть → группы безопасности** (или «Security groups»)
2. Создайте группу `gurman` (или откройте созданную автоматически для ВМ) → **Добавить правило**:
   - Диапазон портов: `3000`
   - Протокол: TCP
   - Источник: 0.0.0.0/0
3. Привяжите эту группу к ВМ (Compute Cloud → ваша ВМ → изменить → сетевые настройки).

## Шаг 3. Установить сервер на ВМ

Подключитесь к ВМ (на Windows: PowerShell → `ssh логин@адрес`) и выполните по одной команде:

```bash
# 1. Установить Node.js и git
sudo apt update && sudo apt install -y nodejs npm git

# 2. Скачать проект (замените на адрес вашего репозитория на GitHub)
git clone https://github.com/ВАШ_ЛОГИН/gurman-site.git gurman

cd gurman

# 3. Установить зависимости и собрать сайт
npm install
npm run build

# 4. Запустить сервер в фоне (pm2 — перезапустит его сам, если что-то упадёт)
sudo npm install -g pm2
pm2 start server/server.js --name gurman
pm2 save
pm2 startup   # выполните команду, которую pm2 напечатает в ответ
```

## Шаг 4. Проверить

- Откройте в браузере `http://АДРЕС-ВМ:3000` — должен открыться сайт
- Откройте `http://АДРЕС-ВМ:3000/kitchen` — экран кухни. Откройте его на планшете на кухне и держите включённым

## Шаг 5. Подключить сайт и приложение (одна строка!)

Осталось вписать адрес ВМ в начало файла `src/api.js`:

```js
const APP_SERVER_URL = 'http://158.160.12.34:3000'; // ваш адрес ВМ
```

После этого:
- **Сайт** — закоммитьте изменение и запушьте в GitHub: GitHub Actions сам пересоберёт и выложит сайт, заказы с сайта пойдут на ВМ
- **Приложение** — `npm run build` → `npx cap sync android` → Run в Android Studio
- **Кухня** — планшет открывает `http://адрес-ВМ:3000/kitchen`

## Обновление меню на сервере

После изменений (например, новые цены) на ВМ достаточно:

```bash
cd gurman
git pull
npm run build
pm2 restart gurman
```
