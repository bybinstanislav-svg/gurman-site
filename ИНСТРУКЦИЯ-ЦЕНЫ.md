# Как менять цены и меню (инструкция для VS Code)

Все цены — в одном файле: **`src/menuData.js`**

## Быстрая шпаргалка

1. Открой `src/menuData.js`
2. Найди позицию через **Ctrl+F**
3. Поменяй число (цену)
4. Слева внизу нажми иконку **веток** → напиши комментарий → **Commit** → **Sync Changes**
5. Готово — всё обновится само

| Где | Через сколько |
|---|---|
| Сайт гурман-супермаркет.рф | 1–2 минуты |
| Приложение (у клиентов) | при следующем открытии |
| Экран кухни | до 5 минут |
| ТВ | до 5 минут |

Собирать APK для цен — **не нужно**.

## Структура файла src/menuData.js

```
PIZZA_ADDONS   — цены доп-ингредиентов пиццы (сыр, бекон...)
MENU_DATA      — все 52 позиции: пицца → Фаст Фуд → Мангал
TV_DATA        — цены для телевизоров (только особые, например «Кусок» пиццы)
```

Позиция выглядит так:
```js
{
  id: 24,
  name: 'Картофель по-деревенски',
  description: 'Описание блюда...',
  price: 65,              ← цена
  unit: '100 г.',         ← подпись «за 100 г» (если есть)
  image: 'kartofel-derevna.png',
  category: 'fastfood'    ← категория: pizza / fastfood / mangal
},
```

У пицц цена в `variants` (размеры):
```js
variants: [
  { label: '20 см', price: 325 },
  { label: '30 см', price: 595 }
],
```

## Важно знать

- **Убрать блюдо с продажи** — не в коде! На экране кухни кнопка **«Стоп-лист»** → переключатель у позиции. Ночью (19:00–10:00 МСК) всё встаёт на стоп автоматически
- **ТВ показывает не всё**: состав позиций для ТВ — в файле `tv/src/TvMenu.jsx` (вшитые списки pizzaItems / fastfoodItems / mangalItems). Цены на ТВ подставляются из `TV_DATA` по названию позиции — название в MENU_DATA и TV_DATA должно совпадать буква в букву
- **Меняешь цены на ТВ** — правь их в `TV_DATA` (и обычную цену тоже, если она отличается)

## После Commit и Sync — проверь себя

1. Открой сайт через 2 минуты — цена поменялась?
2. Если нет — открой этот файл на GitHub (репозиторий → src/menuData.js) и убедись, что изменение ушло

## Если что-то сломалось

- Сайт белый/ошибка → напиши разработчику (или проверь последний коммит: VS Code → Source Control → история)
- Сервер сам синхронизируется с GitHub каждые 5 минут и перезапускается — правки доходят даже без перезапуска вручную
